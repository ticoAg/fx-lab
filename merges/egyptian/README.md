# 埃及神话（`egyptian`）

第 3 组。共 24 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 沙金 | sand | `#E7D3A1` |
| 青金石 | lapis | `#1F4E79` |
| 夜青金 | deep lapis | `#16324F` |
| 金 | gold | `#C4922A` |
| 红玉髓 | carnelian | `#C4652F` |
| 绿松石 | turquoise | `#1F8A7A` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
