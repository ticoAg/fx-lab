## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 浅陶 | light clay | `#E6C99A` |
| 陶土 | clay | `#C46A3A` |

| 赤玉 | carnelian | `#7A2E2A` |
| 高光 | highlight | `#FFFFFF` |
