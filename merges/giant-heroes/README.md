# 巨人英雄（`giant-heroes`）

第 12 组。共 30 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 麦色 | wheat | `#E4C99A` |
| 牛蓝 | ox blue | `#3A6EA5` |
| 松绿 | pine | `#2F4A32` |
| 皮革 | leather | `#8C5A32` |
| 铁 | iron | `#5C6570` |
| 砖红 | brick | `#A33B2B` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
