# 日本妖怪（`onmyoji-yokai`）

第 14 组。共 54 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 骨色 | bone | `#E7DCC8` |
| 朱红 | vermilion | `#D6453D` |
| 靛蓝 | indigo | `#1E2A4A` |
| 金 | gold | `#E2B34A` |
| 松绿 | pine | `#2F4A3A` |
| 幽灵蓝 | ghost blue | `#8FB4C9` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
