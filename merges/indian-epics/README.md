## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 藏红 | saffron | `#E07A2F` |
| 朱红 | kumkum | `#C23A4A` |
| 孔雀绿 | peacock | `#1F6B5A` |
| 金 | gold | `#E2B33A` |
| 靛蓝 | indigo | `#2A3358` |
| 莲粉 | lotus | `#E7A0B4` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
