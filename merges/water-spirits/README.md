# 水妖精灵（`water-spirits`）

第 8 组。共 60 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 浪沫 | foam | `#D5EBE6` |
| 青绿 | teal | `#1F7A78` |
| 深潮 | deep tide | `#134E55` |
| 珊瑚 | coral | `#E07A6A` |
| 海藻 | kelp | `#7BA05B` |
| 夜海 | night sea | `#1E3358` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
