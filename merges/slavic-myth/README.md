# 斯拉夫神话（`slavic-myth`）

第 16 组。共 36 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 桦白 | birch | `#E4E0D4` |
| 林黑 | forest black | `#243028` |
| 余烬 | ember | `#C23A2E` |
| 金 | gold | `#E0B15A` |
| 雪 | snow | `#F4F1EA` |
| 血红 | blood | `#5C2A2A` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
