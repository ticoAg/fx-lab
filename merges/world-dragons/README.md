# 世界龙族（`world-dragons`）

第 7 组。共 55 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 鳞光 | scale light | `#D7E0C8` |
| 鳞绿 | scale | `#2F6B45` |
| 深鳞 | deep scale | `#1E4030` |
| 余烬 | ember | `#D85A2A` |
| 金 | gold | `#E0B15A` |
| 风暴 | storm | `#3D4F6B` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
