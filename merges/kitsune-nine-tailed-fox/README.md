# 狐仙（`kitsune-nine-tailed-fox`）

第 2 组。共 18 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 米白 | rice paper | `#F6E7D4` |
| 朱红 | vermilion | `#D6453D` |
| 深朱 | deep vermilion | `#8E2E2A` |
| 金 | gold | `#E3B34C` |
| 松绿 | pine | `#2F4A3C` |
| 靛蓝 | indigo | `#2A3358` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
