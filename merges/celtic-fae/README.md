# 凯尔特精怪（`celtic-fae`）

第 15 组。共 42 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 浅苔 | pale moss | `#D5E0C4` |
| 苔绿 | moss | `#3E6B3A` |
| 暮紫 | twilight | `#6B4A8A` |
| 金 | gold | `#E0B15A` |
| 浆果 | berry | `#A33B4A` |
| 雾蓝 | mist blue | `#7FA0B5` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
