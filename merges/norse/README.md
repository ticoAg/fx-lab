# 北欧神话（`norse`）

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 冰 | ice | `#D5DDE3` |
| 峡湾蓝 | fjord | `#3E6F8C` |
| 深海 | deep water | `#1E3A4C` |
| 卢恩红 | rune red | `#8E2F2B` |
| 蜜金 | mead gold | `#C4A15A` |
| 木 | wood | `#6B5344` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
