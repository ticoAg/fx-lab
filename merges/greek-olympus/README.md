# 希腊神话（`greek-olympus`）

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 大理石 | marble | `#F3E6D0` |
| 爱琴蓝 | aegean | `#1F6A8A` |
| 深海 | deep sea | `#16384A` |
| 金 | gold | `#C9A24A` |
| 陶土 | terracotta | `#C4653A` |
| 酒红 | wine | `#6B2D4A` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
