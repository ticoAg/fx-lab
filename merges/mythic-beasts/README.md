# 西方神兽（`mythic-beasts`）

第 9 组。共 54 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 大理石 | marble | `#F0E2C4` |
| 绯红 | crimson | `#8E1E2A` |
| 金 | gold | `#C9A227` |
| 青铜 | bronze | `#8A6232` |
| 蓝宝石 | sapphire | `#1E4E8C` |
| 叶绿 | leaf | `#4A6741` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
