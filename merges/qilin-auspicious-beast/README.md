# 中华瑞兽（`qilin-auspicious-beast`）

第 6 组。共 42 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 淡金 | pale gold | `#F0D48A` |
| 朱 | cinnabar | `#C23A2E` |
| 深朱 | deep cinnabar | `#8E1F24` |
| 玉 | jade | `#2F6B4F` |
| 金 | gold | `#E2B33A` |
| 紫 | purple | `#5C3D7A` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
