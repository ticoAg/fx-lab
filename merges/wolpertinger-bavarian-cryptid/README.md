# 鹿角兔（`wolpertinger-bavarian-cryptid`）

第 1 组。共 12 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 暖纸 | warm paper | `#F3E6C8` |
| 苔绿 | moss | `#6B8F4E` |
| 松绿 | pine | `#3E6B3A` |
| 鹿角棕 | antler | `#8C4A2F` |
| 浆果红 | berry | `#C45C3E` |
| 麦金 | wheat gold | `#E0B15C` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。

## 来源

- `wolpertinger-bavarian-cryptid`：6 件
- `jackalope-prairie-cryptid`：6 件
