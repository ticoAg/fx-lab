# 世界秘兽（`cryptids`）

第 10 组。共 55 件。描边保持 `currentColor`，填色收进下面这一套调色板。

## 调色板

| 角色 | Role | 色值 |
| --- | --- | --- |
| 泥色 | mud light | `#C8B89A` |
| 土 | earth | `#6B5A3E` |
| 松绿 | pine | `#2F4A32` |
| 琥珀 | amber | `#C47A2A` |
| 暗红 | dark red | `#7A2E2E` |
| 雾灰 | fog | `#3E4650` |
| 高光 | highlight | `#FFFFFF` |
| 眼墨 | eye ink | `#3A2C22` |

眼睛与近黑中性色收成 `#3A2C22`，近白高光收成 `#FFFFFF`。其余填色按色相和明度就近贴到表内色，阴影的透明度不动。
